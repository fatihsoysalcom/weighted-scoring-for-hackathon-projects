# Weighted Scoring for Hackathon Projects

This example demonstrates a simple weighted scoring system for hackathon projects. It simulates multiple judges evaluating projects based on predefined criteria, each with a specific weight. The script calculates a final weighted score for each project, illustrating how a structured approach can make hackathon judging more objective and reduce the "luck factor" by systematically combining evaluations.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
